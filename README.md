## Features

- **Signature Aesthetic:** Deep midnight violet-blue ambient gradient home screen combined with fluid liquid glassmorphism.
- **Cupertino Design System:** Refined iOS-style controls, SF glyph iconography, and smooth spring physics.
- **Library Simplicity:** Clean, focused access to your Local Downloads and Liked Songs.
- **High-Quality Audio Playback:** Dual-engine audio resolution featuring 320kbps CD-quality JioSaavn streaming and optimized YouTube playback with bot mitigation.
- **Background & Lock Screen Controls:** Full Media3 / ExoPlayer background audio engine with notification controls and lock-screen support.
- **Synchronized Lyrics:** Dynamic lyrics support with synchronized scroll highlighting.
